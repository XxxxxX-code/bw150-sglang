# 可视化对比页

单文件、离线、零依赖的对比页。直接双击 `index.html` 打开即可，不需要起服务、不联网。
（数据以 JS 对象内联在页面里，所以 `file://` 打开也不会被 CORS 拦住。）

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | **产物**。自包含单页，唯一需要给出去的文件。 |
| `extract.py` | 从 `../result/` 下的原始 `bench_serving` 日志解析出 `data.json`（这些日志在提交包里的归档位置是 `submit/logs/20_sharegpt_*/`、`submit/logs/10_sla/`、`submit/logs/30_precision/`） |
| `data.json` | 中间产物。页面上每个数字都能在这里查到来源文件 |
| `template.html` | 页面模板，留 `__DATA_JSON__` 占位符 |
| `build.py` | 把 `data.json` 内联进模板，生成 `index.html` |
| `smoke.js` | 无浏览器环境下的自检（见下） |

## 重新生成

```bash
cd /data/baseline/viz
python3 extract.py     # 原始日志 -> data.json
python3 build.py       # data.json + template.html -> index.html
node smoke.js          # 自检
```

## 自检做了什么

本机没有浏览器也没有 jsdom，所以 `smoke.js` 带一个最小的 DOM 垫片，
把页面里的渲染函数真跑一遍，能做三件事：

1. **渲染**：完整走一遍初始渲染 + 4 次筛选交互（重按基线、切三档口径），
   收集抛出的异常。
2. **数值体检**：遍历整棵渲染树，任何 `NaN` / `undefined` / `Infinity` 文本都报出来。
3. **几何审计**：按字符宽度估算每个 `<text>` 的盒子，检查越出画布边界和同图内互相重叠。
   `CW=<宽度> node smoke.js` 可以换容器宽度跑，最窄应测 320（CSS 网格的最小列宽）。

垫片不是浏览器，它证明的是「逻辑和数据没问题」，**不替代肉眼看排版**。

## 数字口径

- 页面所有数字与 `submit/REPORT.md` 一致。改了报告就要同步改这里。
- **SLA 两侧一律同一套协议**（每档并发 n=6、无预热、取中位数），基线读到哪就是哪：
  4K 16 → **32**、64K 3 → **6**，均为 **+100%**。早期曾用 n=4 探到一组更宽松的基线读数
  并据此申报过 +25%，那是口径不一致，已作废；页面上不再有任何需要选择口径的数字。
- 迭代轨迹图只画 **B2 基线 → 最终配置** 两端。中间的「参考配置 / 并发解锁 / 上下文修复」
  属优化探索期配置，原始日志未随本次重跑归档（见 `submit/REPORT.md` 附录「日志归档范围声明」），
  画成柱子会让人误以为有日志可查，故不画；基线选择器里也因此只有 B2 一个选项。
- GSM8K 的差值按表里显示的那两个两位小数相减（96.35 − 96.19 = **0.16 pp**），
  用原始值算是 0.1522 → 0.15，会和读者自己一减对不上。
- 色板经 `validate_palette.js` 校验：分类色（浅/深）、序数色阶（浅/深）四套全部 PASS。
  状态色（good/warning/critical）按规范固定不随主题切换，故只在基座块里定义。
